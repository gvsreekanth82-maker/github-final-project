\# Code of Conduct



\## Our Pledge

We pledge to make participation in this project a respectful experience.



\## Our Standards

Examples of positive behavior include respect and cooperation.



\## Enforcement Responsibilities

Project maintainers are responsible for enforcing standards.



\## Scope

This code applies to all project spaces.



\## Enforcement

Instances of abusive behavior may be reported to project maintainers.



\## Enforcement Guidelines

Maintainers will follow appropriate procedures when reviewing reports.



\## Attribution

This Code of Conduct is adapted from community standards.
